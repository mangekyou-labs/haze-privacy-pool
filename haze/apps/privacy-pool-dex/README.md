# Haze Privacy Pool DEX

This independently deployable frontend owns the end-user product shell. T5.1 ships the Haze
design tokens, privacy-copy glossary, accessible primitives, and `pool-user` route/API guards.
T5.2 adds `createDexApp`: wallet onboarding, the six user workflows, public warnings before
signature, local-vault history/recovery, and a static alpine-volcanic HTML renderer.

The package remains library-first. A hosted Next.js listener is T6.2.
